# StudyTop

דשבורד לימודי אישי בעברית (RTL) - עוזר לתכנן מערכת שעות, שיעורי בית, בחנים, סיכומים ועוד.

בהשראת הרעיון הכללי של מערכת WebTop הבית ספרית, אך ללא שימוש בעיצוב, לוגו, קוד או מיתוג שלה. אין חיבור ל-WebTop ואין שמירת מידע אישי או סיסמאות של מערכות בית הספר.

## הרצה

אין צורך ב-npm או בשרת build אמיתי, אבל **אי אפשר פשוט לפתוח את index.html בלחיצה כפולה** - דפדפנים חוסמים טעינת מודולי JavaScript (`type="module"`) מכתובת `file://` מסיבות אבטחה. צריך להגיש את התיקייה משרת מקומי פשוט. הדרך הקלה ביותר:

**אופציה 1: תוסף Live Server ב-VS Code (מומלץ, בלי טרמינל)**
1. ב-VS Code, פתחו את סרגל התוספים (Extensions) וחפשו "Live Server" (של Ritwick Dey) והתקינו.
2. לחיצה ימנית על `index.html` בעץ הקבצים ← "Open with Live Server".
3. הדפדפן ייפתח אוטומטית בכתובת כמו `http://127.0.0.1:5500`.

**אופציה 2: שרת Python** (אם מותקן Python במחשב)

```
python -m http.server 8080
```

ואז לפתוח בדפדפן: `http://localhost:8080`

## חשבונות משתמש (מקומי בלבד)

בכניסה ראשונה לאתר מוצג מסך הרשמה/התחברות. החשבון (שם משתמש + סיסמה) נשמר **רק בדפדפן הזה, במחשב הזה** - אין שרת, אין ענן. אפשר ליצור כמה חשבונות על אותו מחשב; לכל חשבון יש נתונים לימודיים נפרדים לגמרי (מערכת שעות, שיעורי בית, ציונים וכו') - שום ערבוב בין משתמשים. הסיסמה לעולם לא נשמרת כטקסט רגיל - רק hash (PBKDF2 דרך Web Crypto API) + salt אקראי לכל משתמש. אם מוחקים את נתוני הדפדפן, גם החשבונות נמחקים - אין דרך לשחזר אותם ואין התחברות ממחשב אחר.

בהרשמה/התחברות ראשונה בלבד, לפני הדשבורד, מוצג מסך "הגדרת פרופיל לימודי" - שם, כיתה, ובחירת המקצועות האמיתיים שהמשתמשת לומדת (מרשימה מוכנה של 18 מקצועות נפוצים + אפשרות "אחר"). המקצועות שנבחרים הופכים ישירות לרשומות אמיתיות במסך "מקצועות" - אין יותר זריעה אוטומטית של נתוני דוגמה מזויפים; כל משתמש מתחיל עם המקצועות האמיתיים שלו בלבד. משתמש שכבר עבר את זה לא רואה את המסך שוב, וניתן לערוך שם/כיתה בהמשך דרך "הגדרות" (המקצועות עצמם מנוהלים במסך "מקצועות").

**קידום כיתה אוטומטי:** בכל 1 בספטמבר (מחושב יחסית לתאריך הנוכחי בכל טעינת עמוד, לא תאריך קבוע בקוד), הכיתה מתקדמת אוטומטית בכיתה אחת (עד י"ב, שם היא נעצרת). המשתמשת יכולה תמיד לשנות את הכיתה ידנית דרך הגדרות ← עריכת פרופיל לימודי - שינוי ידני "מאפס את השעון" עד ה-1 בספטמבר הבא ולא נדרס מיד.

## נתונים

כל הנתונים נשמרים בדפדפן בלבד (`localStorage`, בנפרד לכל משתמש) - שום דבר לא נשלח לשרת חיצוני. אפשר לייצא/לייבא את הנתונים כקובץ JSON ולמחוק את כל הנתונים (של המשתמש הנוכחי בלבד) ממסך ההגדרות.

## מבנה הפרויקט

```
css/       עיצוב (RTL, מצב בהיר/כהה, רכיבים משותפים, מסך התחברות/onboarding)
js/
  app.js         נקודת הכניסה - בודקת התחברות + סטטוס פרופיל, ומציגה מסך אימות/הגדרת פרופיל/דשבורד
  router.js      ניתוב בין מסכים לפי hash בכתובת
  models/        הגדרות טיפוסים (JSDoc)
  data/          שכבת localStorage (פר-משתמש)
  auth/          הרשמה/התחברות: הצפנת סיסמה, רישום משתמשים, session, טפסים
  onboarding/    מסך הגדרת פרופיל לימודי (פעם אחת, למשתמש חדש) + קטלוג מקצועות/כיתות
  utils/         לוגיקת חישוב (המרות, ציונים, מתכנן שיעורי בית, ועוד)
  components/    רכיבי UI משותפים (סיידבר, מודל, טוסט, מצב ריק)
  pages/         מסך לכל פריט בתפריט הניווט (מוגנים - נגישים רק אחרי התחברות+פרופיל)
tests/           דף בדיקות עצמאי לפונקציות החישוב (ללא npm)
```

## מצב נוכחי

**עובד באמת:**
- שלד האפליקציה: ניווט, RTL, מצב בהיר/כהה, תפריט נפתח במובייל
- הרשמה/התחברות מקומית + הגדרת פרופיל לימודי חד-פעמית (ראו למעלה)
- דף הבית - שיעורי היום, שיעורי בית קרובים, מבחן קרוב, ממוצע ציונים, התקדמות שבועית
- מערכת שעות - הוספה/עריכה/מחיקה של שיעורים, אזהרת חפיפת שעות
- שיעורי בית - ניהול משימות מלא, סטטוסים, סימון באיחור
- מתכנן שבועי חכם - יצירת הצעות תזמון לפי האלגוריתם המבוסס-כללים, אישור/שינוי זמן/הסרה
- מסכם טקסטים - גרסת דמו מקומית (בלי AI/אינטרנט): סיכום קצר/בינוני/מפורט, נקודות מרכזיות, ושאלות תרגול (השלמת מילה חסרה) מבוססי ניתוח תדירות מילים. לסיכום עמוק יותר עם בדיקת עובדות ברשת - יש להשתמש בסקיל `/sum` ישירות בצ'אט (מחוץ לאתר), לא באתר עצמו.
- בודק איות - גרסת דמו מקומית (בלי אינטרנט): כלל אותיות סופיות/לא-סופיות (מדויק, בלי חריגים), זיהוי הקלדה כפולה בטעות, ורשימה קטנה של טעויות נפוצות ומוכרות. אפשר להחליף/להתעלם לכל הצעה, ולהעתיק את הטקסט המתוקן. לבדיקה מדויקת יותר - סקיל `/spell` בצ'אט (מחוץ לאתר).
- ממיר יחידות - אורך, מסה, נפח, זמן, טמפרטורה, שטח, מהירות. מציג גם את דרך החישוב, לא רק את התוצאה. כפתור החלפת כיוון, ואימות קלט (מספר שלילי נחסם חוץ מטמפרטורה).
- מחשבון ציונים - הוספה/עריכה/מחיקה של ציונים לכל מקצוע, ממוצע משוקלל לכל מקצוע, ממוצע כללי (ממוצע-של-ממוצעים), אזהרה אם סכום המשקלים במקצוע שונה מ-100%, ומחשבון "כמה חסר כדי להגיע ליעד" - בניסוח תומך ולא שיפוטי.
- מחולל בחנים - **מותאם אישית**: מציג רק את המקצועות מהפרופיל שלך, ורק נושאים המתאימים לכיתה שלך (מתוך קטלוג לימודי מקומי, ראו טבלת כיסוי למטה). אפשר לסמן לכל נושא סטטוס למידה (לומדת עכשיו / כבר למדתי / עדיין לא / הסתרה), לבחור כמה נושאים לבוחן אחד, ולהוסיף נושא אישי אם לא נמצאה התאמה. ניקוד אוטומטי, הצגת תשובות נכונות, ניסיון חוזר, והיסטוריית בחנים.
- מקצועות - הוספה/עריכה/מחיקה של מקצועות (שם, מורה, צבע), עם כרטיס סיכום לכל מקצוע: שיעורים בשבוע, משימות פתוחות, ממוצע נוכחי, בוחן אחרון, מבחן קרוב. מחיקת מקצוע מוחקת בזהירות (עם אזהרה מפורטת) גם את כל השיעורים/משימות/ציונים/בחנים שלו.
- הגדרות - כרטיס "עריכת פרופיל לימודי" (שם/כיתה), שם תצוגה, מצב בהיר/כהה (משפיע מיידית), אורך מקטע לימוד מומלץ, התראות בתוך האפליקציה, ניהול שעות פנויות (בשימוש ע"י המתכנן החכם), ייצוא/ייבוא נתונים כקובץ JSON, מחיקת כל הנתונים (עם אזהרה ברורה), וכרטיס "דירוג האפליקציה" לצפייה/עדכון הדירוג שנתת.
- חלון דירוג אפליקציה - מופיע אוטומטית פעם אחת לכל משתמשת, 60 דקות (מצטברות, לא ברצף) אחרי הכניסה הראשונה לדשבורד. דירוג 1-5 כוכבים (שורת הכוכבים תמיד LTR - כוכב שמאלי=1, ימני=5 - גם בממשק RTL), עם תצוגה מקדימה במעבר עכבר. אם נסגר בלי לדרג, אפשר להציג שוב אחרי 24 שעות; אם דורגה, לא יוצג שוב. אפשר לשנות דירוג בכל עת דרך הגדרות.

כל שבעת המסכים מהתכנון המקורי בנויים ועובדים, מוגנים מאחורי הרשמה/התחברות מקומית עם נתונים נפרדים לכל משתמש, ועם הגדרת פרופיל לימודי אמיתי בכניסה ראשונה. **שלב 5 שנותר:** בדיקות מקיפות (RTL, מובייל, שמירה אחרי רענון) ושיפורים.

**כלל מובטח:** לכל נושא שיש לו בכלל שאלות, יש **לפחות 7** (רובם 8-10) - כדי שגם בוחן על נושא יחיד יהיה מגוון. שדה "מספר שאלות" במסך הבוחן מתעדכן אוטומטית לפי כמה שאלות באמת זמינות לצירוף הנושאים/רמת הקושי/סוגי השאלות שנבחרו (יכול להיות גם יותר מ-10 אם משלבים כמה נושאים יחד).

**מגבלות שכדאי לדעת:**
- אין חיפוש רשת אמיתי, אין אימות מול משרד החינוך/ראמ"ה, ואין מקורות עם קישורים אמיתיים - זו רשימה מקומית בלבד (הוסבר וסוכם יחד מראש).
- תתי-נושאים מוצגים כמידע בלבד - לא ניתן עדיין לסנן שאלות לפי תת-נושא ספציפי.
- אין חיפוש לפי כיתה סמוכה (למשל אם אין נושאים בדיוק לכיתה שלך, אין נפילה לכיתה קרובה עם סימון) - רק התאמה מדויקת או "לא נמצא".
- "האם לכלול פתרונות" / "הצג הסבר אחרי כל שאלה" - התשובה הנכונה תמיד מוצגת בתום הבוחן; אין עדיין הסבר טקסטואלי נפרד מעבר לתשובה הנכונה עצמה.
- אין סוג שאלה של "סידור מילים בגרירה" - במקום זה, שאלות סידור-משפט (למשל בערבית) ממומשות כשאלה אמריקאית עם כמה סדרי מילים אפשריים לבחירה.
- שאלות פתוחות יכולות עכשיו לקבל כמה תשובות תקינות (למשל כמה תעתיקים עבריים מקובלים למילה בערבית) - `correctAnswer` יכול להיות מחרוזת בודדת או מערך של תשובות מקובלות. הבדיקה גם אינה רגישה יותר לאותיות סופיות עבריות (ך/ם/ן/ף/ץ) ולגרשיים/מרכאות.
- מקצוע "חינוך גופני" מוצג ונשמר כרגיל במסך "מקצועות" ובשאר האתר, אבל **לא מופיע** ברשימת המקצועות לבחירה במחולל הבחנים (לא רלוונטי לבחני ידע עיוניים).

**מאושר ע"י שקד:** הסיידבר ה"דביק" (sticky) נבדק ועובד כמו שרצתה - נשאר צמוד לחלק העליון יחד עם ברכת הפתיחה בדף הבית.
